# cyph-deck

The Cyph investor pitch deck: a single-page HTML/CSS/JS presentation served at `investors.cyph.city` (S3 + CloudFront) and on GitHub Pages. Layer: Subsidiary/site.

## Talks to

Standalone: yes. No platform service is called. The only shared things are `auth.js` (the one gate, also consumed by event-decks) and the Google Apps Script logger it posts to.

| Service | Direction | Protocol | For what |
|---|---|---|---|
| Google Apps Script web app (`apps-script/Code.gs`) | out | HTTPS POST (`fetch` / `sendBeacon`) from `auth.js` | email gate, one access row per surface per tab session, per-slide dwell timings |
| `site/deck/versions.json` (same host) | out | HTTPS GET from `auth.js` | retired-version check before showing the gate |
| event-decks | in | copies `auth.js`, `base.css`, `favicon.png`, `site/common/viewer.*` | events.cyph.city builds its `/common/` bundle from these files |
| cyph-terraform (`investors.tf`) | in | outputs | bucket + distribution id in `tools/investors.json` |
| cdnjs (anime.js), unpkg (three.js), Google Fonts | out | script/style tags | desktop deck animation and `iso3d.js` canvases |

Events published/subscribed: none.

## Stack

- Static HTML, CSS, vanilla JS (no bundler). Node 20 + `playwright-core` for the export and check tools only.
- No port, no database, no store. Local serving is `make sites` / `make dev-lite` from the monorepo root (`investors.localhost:4700`, via `scripts/cyph-sites.mjs`).
- Deploy: GitHub Pages serves `main:/`; S3 bucket `cyph-investors-prod` behind CloudFront `E3O6S0G9JGGG7L` serves `investors.cyph.city`.

## Layout

```
index.html          all slide content (div.slide#s0..s15) + the viewing-path router in <head>
base.css            reset, :root tokens, station-sign placard, access gate; loads on every device
styles.css          the interactive desktop deck
mobile.css/.js      the phone page view (reads assets/deck-pages/manifest.json)
deck.js             navigation, animations, chapter map (desktop only)
iso3d.js            three.js canvases on the money slide (desktop only)
auth.js             email gate + access/dwell logging; runs on both paths; shared with event-decks
apps-script/        Code.gs, the Google Apps Script logger source (one sheet)
tools/              export-pdf.mjs (PDF + phone pages), check-paths.mjs, publish-investors.mjs,
                    onepager-pages.mjs, investors.json (bucket + distribution id, not secrets)
site/               everything served at investors.cyph.city besides deck versions:
                    index.html (root redirect), 404.html, deck/versions.json, deck/latest/,
                    onepager/ (cyph-onepager.pdf + pages/), common/viewer.js + viewer.css
assets/             images, videos, brands, people, deck-pages/ (generated by npm run pdf)
cyph-deck.pdf       generated by npm run pdf
```

## Run / test / lint

```
npm install
npm run pdf      # tools/export-pdf.mjs: regenerates cyph-deck.pdf AND assets/deck-pages/ (needs system Chrome)
npm run check    # tools/check-paths.mjs: asserts each device fetches only its own path, and #mobile-deck has no anchors/buttons
node tools/publish-investors.mjs site --dry-run
node tools/publish-investors.mjs deck --version <id> --dry-run
```

There is no lint step. To view locally, run `make sites` from the monorepo root and open `http://investors.localhost:4700/`; `auth.js` bypasses the gate on `localhost`, `127.0.0.1` and `*.localhost`.

## Rules for changing this repo

- Slide IDs `s0..s15` must stay contiguous; adding or removing a slide is a lockstep edit across `index.html`, both HUD counters (`#hudCtr`, `#bhudCtr`), and `deck.js` (`T`, `ch`, `bars`, progress denominator, `runA` cases, lock-mode selectors).
- `base.css` loads on both paths; `styles.css` and `mobile.css` never load together. Keep `base.css` self-contained (no `var()` beyond the tokens it defines).
- The phone view carries no links or buttons and never routes into the interactive deck. `npm run check` enforces this.
- `assets/deck-pages/` and `cyph-deck.pdf` are generated by `npm run pdf`; never hand-edit or hand-add.
- Run `npm run pdf` after any slide change so the PDF and phone pages cannot drift from the deck.
- `assets/videos/` holds web `.mp4` only (H.264, no audio); `.mov` masters are not kept in-repo.
- `auth.js` is shared by every gated surface (this deck and event-decks); a change here changes the gate everywhere. Open mode writes nothing to `sessionStorage`, so an open page never unlocks a gated one.
- A deck version must be listed and `live` in `site/deck/versions.json` before it can be published; `live:false` + a site republish retires it.
- The deck sync `--delete`s only inside `s3://cyph-investors-prod/deck/<version>/`; the site sync never deletes. Keep it that way: the two share one bucket.
- Copy is Cash-authored; only make dictated wording changes.
- Dark register: text tokens resolve light (`--charcoal` is cream) on black backgrounds. Typography is Helvetica Neue. See `CLAUDE.md` for colors and slide conventions.

## Deploy

- `.github/workflows/deploy-investors.yml`, branch `main`.
- Push touching `site/**`, `auth.js`, `base.css` or `favicon.png` runs `node tools/publish-investors.mjs site` (no `--delete`; invalidates `/`, `/deck/versions.json`, `/deck/latest/*`, `/onepager/*`, `/common/*`).
- A deck version is a manual `workflow_dispatch` with `target=deck` and `version=<id>`: stages the repo, rewrites `og:url`, syncs to `/deck/<id>/` (assets immutable, html/json no-cache), invalidates `/deck/<id>/*`.
- `/deck/latest/` resolves to `current` in `versions.json`; that is the link handed out.
- GitHub Pages keeps serving `main:/` untouched by the workflow.
