# cyph-deck

The Cyph investor pitch deck: a single-page HTML/CSS/JS presentation served on GitHub Pages. Layer: Subsidiary/site. (investors.cyph.city is no longer this deck: since 2026-11-10 it is cyph-web's investors research dashboard; nothing here publishes to it.)

## Talks to

Standalone: yes. No platform service is called. The only shared things are `auth.js` (the one gate, also consumed by event-decks) and the Google Apps Script logger it posts to.

| Service | Direction | Protocol | For what |
|---|---|---|---|
| Google Apps Script web app (`apps-script/Code.gs`) | out | HTTPS POST (`fetch` / `sendBeacon`) from `auth.js` | email gate, one access row per surface per tab session, per-slide dwell timings (per-5s-segment watch time on the trailer) |
| event-decks | in | copies `auth.js`, `base.css`, `favicon.png`, `site/common/viewer.*` | events.cyph.city builds its `/common/` bundle from these files |
| cyph-terraform (`partners.tf`, `trailer.tf`) | in | outputs | bucket + distribution id in `tools/partners.json`, `tools/trailer.json` |
| cdnjs (anime.js), unpkg (three.js), Google Fonts | out | script/style tags | desktop deck animation and `iso3d.js` canvases |

Events published/subscribed: none.

## Stack

- Static HTML, CSS, vanilla JS (no bundler). Node 20 + `playwright-core` for the export and check tools only.
- No port, no database, no store. Open `index.html` directly, or serve the repo root with any static server.
- Deploy: GitHub Pages serves `main:/`. partners.cyph.city and trailer.cyph.city have their own buckets (Deploy below).

## Layout

```
index.html          all slide content (div.slide#s0..s13) + the viewing-path router in <head>
base.css            reset, :root tokens, station-sign placard, access gate; loads on every device
styles.css          the interactive desktop deck
mobile.css/.js      the phone page view (reads assets/deck-pages/manifest.json)
deck.js             navigation, animations, chapter map (desktop only)
iso3d.js            three.js canvases on how it works + the money slide (desktop only)
cosmos.js           the resource cosmos on how it works, step 01 (desktop only)
partners.html       GENERATED partner (non-VC) deck; built by tools/build-partners.mjs, never hand-edited
partners/           the partner deck's own sources: close.html,
                    partners.js (its deck.js), partners.css (on top of styles.css)
partners/one-off/   single-partner documents, one folder each (deck.json + its PDF); rendered by
                    event-decks, never staged or published (see partners/one-off/README.md)
trailer.html        trailer.cyph.city: the trailer video behind the same gate (<video data-cyph-track>)
trailer/            trailer.mp4, the web encode served there; trailer/README.md = how to swap in a new cut
auth.js             email gate + access/dwell logging; runs on both paths; shared with event-decks
apps-script/        Code.gs, the Google Apps Script logger source (one sheet)
tools/              export-pdf.mjs (PDF + phone pages), check-paths.mjs, publish-partners.mjs,
                    publish-trailer.mjs, partners.json + trailer.json (bucket + distribution id, not secrets)
site/               shared by the partner and trailer hosts: 404.html, common/viewer.js + viewer.css;
                    onepager/cyph-onepager.pdf (the one-pager's export, not served)
assets/             images, videos, brands, people, deck-pages/ (generated by npm run pdf)
cyph-deck.pdf       generated by npm run pdf
cyph-partners.pdf   generated by npm run partners (with assets/partner-pages/)
seeded-sources/     the full list behind s8's "500+ seeded partners" (DPLA institutions CSV); read by nothing
```

## Run / test / lint

```
npm install
npm run pdf      # tools/export-pdf.mjs: regenerates cyph-deck.pdf AND assets/deck-pages/ (needs system Chrome)
npm run partners # build partners.html from index.html + partners/, then export cyph-partners.pdf + assets/partner-pages/
npm run check    # tools/check-paths.mjs: asserts each device fetches only its own path, and #mobile-deck has no anchors/buttons
node tools/publish-partners.mjs --dry-run
node tools/publish-trailer.mjs --dry-run
```

There is no lint step. `auth.js` bypasses the gate on `localhost`, `127.0.0.1` and `*.localhost`.

## Rules for changing this repo

- Slide IDs `s0..s13` must stay contiguous; adding or removing a slide is a lockstep edit across `index.html`, both HUD counters (`#hudCtr`, `#bhudCtr`), and `deck.js` (`T`, `ch`, `bars`, progress denominator, `runA` cases, lock-mode selectors).
- `base.css` loads on both paths; `styles.css` and `mobile.css` never load together. Keep `base.css` self-contained (no `var()` beyond the tokens it defines).
- The phone view carries no links or buttons and never routes into the interactive deck. `npm run check` enforces this.
- `assets/deck-pages/` and `cyph-deck.pdf` are generated by `npm run pdf`; never hand-edit or hand-add.
- Run `npm run pdf` after any slide change so the PDF and phone pages cannot drift from the deck.
- `assets/videos/` holds web `.mp4` only (H.264, no audio); `.mov` masters are not kept in-repo.
- `auth.js` is shared by every gated surface (this deck and event-decks); a change here changes the gate everywhere. Open mode writes nothing to `sessionStorage`, so an open page never unlocks a gated one.
- Nothing in this repo publishes to `cyph-investors-prod` (investors.cyph.city belongs to cyph-web since 2026-11-10). Do not add a publisher for it.
- The partner deck reuses investor slides verbatim: after editing s0-s2, s5-s7, s11 or s13, run `npm run partners` so partners.html, its PDF and its phone pages follow.
- Copy is Cash-authored; only make dictated wording changes.
- Dark register: text tokens resolve light (`--charcoal` is cream) on black backgrounds. Typography is Helvetica Neue. See `CLAUDE.md` for colors and slide conventions.

## Deploy

- GitHub Pages serves `main:/`; no workflow touches it.
- partners.cyph.city: `.github/workflows/deploy-partners.yml` runs `node tools/publish-partners.mjs` on every push to main that touches the partner deck or its sources (also by hand: workflow_dispatch, or the script from the Mac with `AWS_PROFILE=cyph`). CI rebuilds partners.html and fails if it differs from the commit, so run `npm run partners` before pushing an edit to a reused slide. S3 bucket `cyph-partners-prod` + CloudFront from cyph-terraform `partners.tf`; ids in `tools/partners.json`. The stage is an allow-list and refuses to publish if any investor-only file (index.html as the investor deck, deck.js, cyph-deck.pdf, assets/deck-pages/) is in it.
- trailer.cyph.city: `.github/workflows/deploy-trailer.yml` runs `node tools/publish-trailer.mjs` on every push to main that touches `trailer.html`, `trailer/**`, the gate files or the script (also by hand: workflow_dispatch, or the script from the Mac with `AWS_PROFILE=cyph`). S3 bucket `cyph-trailer-prod` + CloudFront from cyph-terraform `trailer.tf`; ids in `tools/trailer.json`. The stage is an allow-list: the page, the gate files, `trailer/trailer.mp4`, `404.html` and `/common/`. **New trailer cut: follow [trailer/README.md](trailer/README.md).**
